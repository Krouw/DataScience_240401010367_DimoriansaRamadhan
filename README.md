Awalnya saya merasa Data Science adalah bidang yang sangat sulit dan hanya dipahami oleh orang-orang yang ahli matematika atau pemrograman. Namun setelah mempelajarinya sedikit demi sedikit, saya mulai memahami bahwa Data Science sebenarnya adalah proses bagaimana data dapat diolah menjadi informasi yang berguna.

Namun dari situ saya merasa bahwa belajar Data Science bukan hanya tentang hasil akhir, tetapi tentang proses memahami data secara perlahan.

4. Tools / Library yang Digunakan

Beberapa tools dan library yang digunakan selama proses pembelajaran antara lain:

* Python
  Bahasa pemrograman utama yang digunakan dalam seluruh praktikum.

* Pandas
  Digunakan untuk membaca, mengelola, dan memanipulasi dataset.

* NumPy
  Digunakan untuk operasi numerik dan pengolahan array.

* Matplotlib
  Digunakan untuk membuat visualisasi data seperti grafik dan plot.

* Seaborn
  Digunakan untuk membuat visualisasi statistik yang lebih menarik dan mudah dipahami.

* Scikit-learn
  Digunakan untuk preprocessing data dan membuat model machine learning sederhana.

* Google Colab
  Digunakan sebagai media menjalankan notebook secara online.

* TensorFlow
  Digunakan untuk membangun model Artificial Neural Network (ANN).
  
* mlxtend
  Digunakan untuk implementasi algoritma Apriori dan Association Rules pada Market Basket Analysis.
